## USAJOBS access request and current terms review — 2026-11-27
The registration confirmation screenshot indicates that USAJOBS sent an email-verification link. It is not proof that the email was verified or that an API key was issued. The Search Jobs endpoint requires the registered email as `User-Agent` and issued token as `Authorization-Key`: https://developer.usajobs.gov/guides/authentication. **The Historic JOAs and Announcement Text endpoints are different: their current API references explicitly state that neither endpoint requires authentication.** See https://developer.usajobs.gov/api-reference/get-api-historicjoa and https://developer.usajobs.gov/api-reference/get-api-announcementtext.

The current published API Terms of Service at https://developer.usajobs.gov/guides/terms-of-service define Public Data to include Search, Historic JOA and Announcement Text API data, and permit copying, storage, adaptation, analysis, publication, redistribution and lawful commercial/noncommercial reuse. Exclusions for separately restricted third-party content still apply. Attribute USAJOBS, include retrieval dates and direct users to official announcements where available; clearly disclose that globalGOV is independent and not endorsed by OPM. Do not imply that historic data represents current vacancies.

A manual, credential-gated smoke workflow is available at `.github/workflows/globalgov-usajobs-probe.yml`. After the owner has received the key and confirmed applicable terms, configure repository Actions secrets `USAJOBS_REGISTERED_EMAIL` and `USAJOBS_API_KEY`, then manually dispatch the workflow with the terms-confirmation input enabled. The workflow reports aggregate counts and a response hash only; it does not store or publish job records. Never paste the API token into source, issues, pull requests, chat or logs. This smoke test is not the production feed adapter or proof of permission to publish.


## USAJOBS Historic JOA and Announcement Text integration — 2026-11-27
The public Historic JOA endpoint is `https://data.usajobs.gov/api/historicjoa`. Its official reference says it returns smaller fields for current and past job postings, supports agency, department, position-series, announcement-number, control-number and open/close date filters, and uses a continuation token for paging. The live endpoint currently reports approximately 3.2 million records and a default page size of 500; globalGOV must not crawl the entire corpus. The new integration fetches one bounded page per user query and exposes a separate historical archive page. It excludes records without a valid effective closing date, records whose effective closing date has not passed, and records whose status conflicts with the closed date.

The Announcement Text endpoint `https://data.usajobs.gov/api/historicjoa/announcementtext` is also public and unauthenticated. globalGOV retrieves long text only after a user requests one exact control number, whitelists documented text fields, and labels instructions as historical. Neither endpoint writes to D1 or automatically creates a current vacancy listing. The Search Jobs endpoint remains separate and requires API credentials.
